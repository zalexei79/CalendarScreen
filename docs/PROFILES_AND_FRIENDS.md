# Профиль, фото и друзья

Настройки → Профиль → «Изменить фото». Выберите изображение до 10 МБ. Браузер декодирует его, обрежет квадрат по центру и создаст JPEG 512×512 без исходных метаданных. Фото сохраняется сразу. Его можно убрать. Для декодирования HEIC/HEIF/AVIF нужна поддержка браузера; при ошибке интерфейс предложит JPG/PNG/WebP.

В профиле также редактируются имя для друзей и личный код (3–24 латинские буквы, цифры или `_`). Поиск по коду по умолчанию выключен. Включить его можно чекбоксом и кнопкой сохранения профиля.

Настройки → Друзья: скопируйте свой код или во вкладке «Добавить» введите точный код друга. Получатель принимает или отклоняет входящую заявку. Есть исходящие заявки с отменой, удаление друзей, блокировка и разблокировка. Разблокировка не восстанавливает дружбу автоматически. Поиск по email и каталог всех аккаунтов не создаются.

## Данные и доступ

- `social_profiles`: только имя для друзей, код, путь фото, видимость. Ни финансовых полей, ни email в социальном API нет.
- Профиль виден владельцу, участникам ожидающей/принятой дружбы, другим вошедшим пользователям при включённой видимости и назначенному Google-администратору с правом просмотра пользователей. Блокировка прекращает социальный доступ в обе стороны.
- Для таблиц включён RLS, прямой доступ `anon` и `authenticated` отозван. RPC записывают только данные вошедшего пользователя и проверяют ожидаемый UUID владельца, чтобы смена аккаунта не перенесла действие на другой аккаунт.
- Приём/отказ разрешён только получателю, отмена — отправителю; нельзя отправить заявку себе или принять свою. Блокировка отменяет существующую связь. Повторные клики по уже ожидающей заявке не создают дубликатов.
- Максимум 20 новых отправок заявок за сутки. После отказа повтор от того же отправителя доступен через сутки. Проверки и переходы состояния выполняются в серверной транзакции.
- Дружба не изменяет RLS календаря, кошелька, PRO или админки.

Фото находятся в приватном bucket `profile-avatars` с лимитом 2 МБ на готовый JPEG. Загрузка и удаление разрешены только в папке своего UUID. Другим разрешено читать только действующее фото доступного им социального профиля. Подписанные ссылки действуют 5 минут; ранее выданная ссылка может работать до истечения срока. Оригинал не загружается; новое фото получает новый путь. После успешной смены старый файл удаляется по возможности. Ссылка на фото не сохраняется в localStorage.

Настройки используют `useSocialProfile` и `SocialAvatar`. Аватары отображаются в собственном профиле, друзьях и административных чатах. Списки друзей и счётчик заявок обновляются каждые 15 секунд в видимой вкладке. Никаких настоящих заявок или фото для развёртывания отправлять не требуется.

## Развёртывание

Применить `supabase/migrations/202610290005_profiles_and_friends.sql` и `202610290006_social_block_visibility.sql` к существующей базе DAYRIS и зарегистрировать обе версии, затем опубликовать frontend. Миграции создают отдельные социальные таблицы, bucket и политики фото; другие данные приложения не мигрируются. Проверка блокировки также запрещает использовать список блокировок для обнаружения неизвестных приватных профилей.
