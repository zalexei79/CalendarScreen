# Огоньки в админке

Пользователи → карточка → **Огонёк**. В обзоре есть быстрый переход, в списке аккаунтов — текущие дни и признак ручной корректировки. Сортировка «Сначала больше огоньков» считает эффективную серию по сегодняшней дате в часовом поясе каждого аккаунта; истёкшие серии показываются как 0.

- **+1 / −1 день** меняют текущую эффективную серию.
- **Установить число дней** задаёт 0–36500. Ноль допустим; отрицательные значения запрещены.
- **Сохранить / восстановить** берёт сохранённое число дней (минимум 1) и фиксирует опорную дату на сегодня. Это разовая помощь, не бессрочная заморозка: обычное истечение после пропусков остаётся.
- Все действия требуют подтверждения выбранного аккаунта и результата. Заметка необязательна. Кто, кому, что изменил и значения до/после атомарно сохраняются в журнале. Фильтр журнала «Только изменения» включает огоньки.

Текущее правило огонька — запись в календарь/кошелёк либо серверная отметка «без трат», а не вход в приложение. Ручное изменение не записывает деньги, не выдаёт и не удаляет отметку «без трат», не подменяет `last_entry_date`, не меняет часовой пояс существующего аккаунта. При отсутствии истории используется UTC. Поэтому ручной счётчик — не объективная оценка интереса человека; это явно обозначено в интерфейсе.

Миграция `202610290001_admin_streak_management.sql` добавляет приватный расчёт состояния, административные RPC `admin_streak_state` / `admin_change_streak`, пометку `admin_adjusted_at` и поля серии в существующий список пользователей. Чтение требует `site_admin_require()`, запись — `site_admin_require(true)` с Google-ограничениями. Прямой пользовательский доступ к изменению таблицы не расширяется. Подтверждённый снимок включает серверную дату: конкурентная запись или смена дня требуют обновления формы. Изменения реально заработанного дня блокируются тем же row lock, что и обычный счётчик. Подписка Realtime на таблицу остаётся прежней; приложение также перечитывает счётчик при обновлении/возврате в окно.

Проверки: `node --test tests/admin-streak-db.test.mjs tests/streak-no-spend-db.test.mjs tests/entry-activity-streak-db.test.mjs`, `npm run build`, `node tests/admin-users-ui-check.mjs`.
