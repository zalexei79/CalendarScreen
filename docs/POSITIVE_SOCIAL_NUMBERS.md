# Положительные номера и социальный интерфейс

Миграция `202610290013_positive_owner_first_numbers.sql` один раз ставит подтверждённый аккаунт владельца первым (номер 1), остальные аккаунты упорядочивает по дате регистрации, затем UUID. Сохранённые номера положительные. Поиск принимает `1`, а также прежние префиксы для совместимости. Номера остаются неизменяемыми; новые выдаются последовательно, удалённые не переиспользуются. Существующие дружбы, история и QR привязаны к UUID и не теряются.

Раздел друзей использует спокойные золотые акценты DAYRIS, ровную сетку вкладок, карточки контактов и крупный номер. QR-карточка приглашает отсканировать QR или добавить отправителя по номеру, чтобы подружиться и получить PRO. Условие первой записи и правила программы вынесены в небольшую подпись; серверные 26/7 дней и ограничения рефералки не меняются.

`202610290014_number_friend_referral.sql` подключает обычную заявку по номеру к тому же `claim_referral`: только для аккаунта без существующего реферала, с сохранением запрета поздних и собственных приглашений. Начисление по-прежнему запускает первая запись, а не дружба. Для аккаунта владельца включён поиск по номеру 1; видимость остальных аккаунтов сохраняется.
