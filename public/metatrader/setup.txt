DAYRIS PRO — MetaTrader 5

Доступно каждому вошедшему пользователю с активным PRO. Пароли, API-ключи и разрешение на торговлю не нужны.

1. Войдите в свой счёт в MT5. В DAYRIS → Площадки → MetaTrader 5 скачайте DAYRIS_MT5.ex5.
2. MT5 → Файл → Открыть каталог данных → MQL5 → Experts. Скопируйте файл туда. Обновите «Советники» в Навигаторе и добавьте DAYRIS_MT5 на один график.
3. В DAYRIS выберите папку %APPDATA%\MetaQuotes\Terminal\Common\Files\DAYRIS.
4. Выберите счёт по номеру и серверу. В карточке будут брокер, Demo/Live/Contest, баланс и время снимка (по брокеру). Нажмите «Подключить и синхронизировать». Импортируется только выбранный счёт в текущий журнал DAYRIS.
5. Для другого счёта войдите в него в MT5 и подключите экспортёр. Снова выберите папку в DAYRIS: оба сохранённых экспорта появятся в списке. Переключение в DAYRIS не переключает счёт в самом терминале. Неактивные счета показывают последний сохранённый снимок, а не текущий баланс.
6. Включите автообновление каждые 30 секунд. Терминал и сайт должны быть открыты в Chrome/Edge на ПК. Закрытие окна подключения не останавливает обновление. После перезагрузки сайта выберите папку снова. Выход из аккаунта, смена счёта, потеря PRO или отключение останавливают автообновление. Отключение не удаляет сделки.
7. На телефоне сделки появятся через существующую облачную синхронизацию DAYRIS. Это локальный мост, не прямое серверное подключение к брокеру как у cTrader. На других браузерах доступен ручной CSV-импорт.

Экспортируются только полностью закрытые позиции. Частичные закрытия объединяются, когда позиция полностью закрыта. В результат включены прибыль, своп, комиссии и сборы входа/выхода. Пополнения и выводы исключены. Отдельные корректировки баланса не распределяются по позициям. Даты — время брокера.
Повторы определяются по маркеру сервера/счёта/позиции в комментарии: сохраняйте его. Коррекции уже импортированных сделок не применяются автоматически. Используйте одно окно DAYRIS для одного торгового счёта, чтобы избежать параллельного импорта.
MT4 пока не проверен и не предлагается как готовое подключение.

ENGLISH
Every signed-in PRO user can connect their own terminal. No passwords, API keys or trading permissions are required.
Install DAYRIS_MT5.ex5 in MT5's data folder under MQL5/Experts, refresh Expert Advisors and attach it to one chart. Choose the DAYRIS common-files folder in desktop Chrome/Edge. Select the account and confirm synchronization into your current DAYRIS journal. Only the selected account is imported, with duplicate markers preserved.
Accounts include broker, server, login, mode, balance and snapshot timestamp, even when there are no closed trades. To add another account, log into it in MT5, attach the exporter and select the folder again. Selecting an account in DAYRIS does not change the terminal login. Inactive accounts show their last snapshot.
Auto-sync requires both terminal and website open on PC. Select the folder again after reloading. Sign-out, changing accounts, disconnecting or losing PRO stops auto-sync. Existing trades are never deleted by disconnecting. Mobile receives saved trades through existing DAYRIS cloud sync. This is a local bridge, not direct broker-cloud access like cTrader.
Fully closed positions only, including entry/exit fees and swap. No deposits/withdrawals; separately posted balance adjustments are not allocated. Broker time is preserved. Corrections to existing imports are not automatically reconciled. Use one DAYRIS window per trading account. MT4 remains unverified.
