Политика конфиденциальности DAYRIS

Дата последнего обновления: 24 сентября 2026 г.

DAYRIS — «Денежный календарь» помогает вести записи о торговых операциях, заметки по торговым дням и планы с напоминаниями. Мы обрабатываем только данные, необходимые для работы этих функций.

1. Какие данные мы обрабатываем

  • Данные аккаунта: адрес электронной почты, имя и идентификатор аккаунта, полученные при входе через Google.
  • Данные, которые вы добавляете: торговые операции, даты, суммы, валюты, инструменты, комментарии, заметки, теги и планы/напоминания.
  • Данные уведомлений: технические данные push-подписки, необходимые для доставки разрешённых вами напоминаний.
  • Данные на устройстве: настройки приложения и временные данные могут храниться в локальном хранилище браузера или приложения.
  • Технические данные: стандартные технические журналы, которые могут автоматически формироваться инфраструктурой хостинга и сервисов авторизации для безопасности и работоспособности.

2. Для чего используются данные

  • для создания аккаунта, входа и синхронизации данных между вашими устройствами;
  • для отображения календаря, статистики, торговых записей и заметок;
  • для создания и доставки напоминаний, если вы разрешили уведомления;
  • для поддержания безопасности, устранения ошибок и улучшения стабильности приложения;
  • для ответа на обращения пользователя и выполнения требований закона.

3. С кем могут обрабатываться данные

Для работы DAYRIS используются сторонние сервисы: Google для входа в аккаунт, Supabase для авторизации и хранения данных, а также Render для размещения веб-приложения. Эти сервисы обрабатывают данные по своим условиям и политикам конфиденциальности. Мы не продаём персональные данные и не используем их для показа рекламных профилей.

4. Push-уведомления

Push-уведомления включаются только после вашего разрешения. Технический идентификатор подписки используется исключительно для доставки выбранных вами напоминаний. Разрешение можно отключить в настройках устройства или браузера; при выходе из аккаунта подписка отключается в приложении.

5. Хранение и удаление данных

Данные аккаунта и связанные с ним записи хранятся, пока аккаунт используется, либо до удаления по вашему запросу. Для запроса на удаление данных напишите на aveel2001@gmail.com с адреса, связанного с аккаунтом, и укажите, что хотите удалить аккаунт DAYRIS и связанные данные. Мы можем сохранить ограниченные сведения, если это необходимо для безопасности или предусмотрено законом.

6. Безопасность

Мы используем защищённое соединение и ограничиваем доступ к данным аккаунта. Однако ни один способ передачи или хранения данных в интернете не гарантирует абсолютную безопасность.

7. Дети

DAYRIS не предназначен для детей младше возраста, установленного применимым законодательством. Мы не стремимся сознательно собирать данные детей.

8. Изменения политики

Мы можем обновлять эту политику при изменении приложения или требований закона. Новая версия будет опубликована на этой странице с новой датой обновления.

9. Контакты
